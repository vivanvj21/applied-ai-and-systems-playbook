# Applied AI & Systems Engineering Playbook

A comprehensive, production-grade repository of enterprise architecture decision records (ADRs), system design patterns, machine learning benchmarks, and full-stack integration blueprints across four core disciplines:

1. **AI Engineering & Multi-Agent Topologies** (LangGraph, MCP, RAG, RAGAS)
2. **Applied Data Science & Machine Learning** (Time-series forecasting, XGBoost, feature pipelines)
3. **Full-Stack & Cloud Architecture** (FastAPI, TypeScript, Azure Functions, APIM Zero-Trust)
4. **Data Analytics & BI Governance** (Power BI DAX, Dataverse modeling, SQL window functions)
